**You'll need:** JUnit 5 and Testcontainers basics, and the support app from Module 5.

The support app had 63 tests, and all of them passed. Then, while writing this module, we started the whole app for the first
time, with a real model and real pgvector, and asked "Where is my order 1042?". It answered "I'm sorry, but I can't assist with
that." The question had found no knowledge documents, so the RAG advisor replaced it with a refusal before the model saw it. No
unit test could catch that, because none ran real retrieval and tools together. The fix is now in Module 5,
in the Tool Calling lesson. This lesson adds the two kinds of test that catch bugs like it:
integration tests against real containers, and evals that grade the answers themselves.

## 1. Spring mental model

Keep the tests you have. Each layer answers a different question:

| Layer | Runs against | Checks | When |
| --- | --- | --- | --- |
| Unit and slice tests | `ScriptedChatModel`, `@WebMvcTest` | Your logic: advisors, tools, errors | Every build |
| Integration tests | Ollama and pgvector in Testcontainers | The wiring: retrieval, filters, tool calls, memory | Every build (needs Docker) |
| Evals | Your production model, graded by a judge model | The answers: relevant, and grounded in the documents | Nightly, and when a prompt or model changes |

These rules come from the 2.1.0 classes and from running the tests below:

- `@ServiceConnection` replaces URL properties. Boot's PostgreSQL support connects the datasource, and pgvector needs nothing
  more because it is PostgreSQL. `spring-ai-spring-boot-testcontainers` adds the Ollama connection, which sets only the base URL.
- A new Ollama container has no models, and `spring.ai.ollama.init.pull-model-strategy` defaults to `never`. Set
  `when_missing`, and allow more than the default 5-minute `timeout` for the first download.
- The Ollama starter also configures a <a href={lessonHref('02-structured-outputs/decision-models')}>decision model</a>, and with
  a pull strategy it downloads `d1-omni:600m` for it. Set `spring.ai.model.decision: none` when the app doesn't use one.
- Model output changes from run to run, so assert on what doesn't: the tool that ran and its arguments, a value only the tool
  result holds, the documents retrieved. Never the wording.
- An evaluator takes an `EvaluationRequest` of question, documents and answer. `RelevancyEvaluator` asks the judge whether the
  answer fits the question and the context. `FactCheckingEvaluator` sends only the documents and the answer, and asks whether
  the answer is supported.
- Both pass only when the judge's whole reply is the word "yes", ignoring case and surrounding space. "Yes." fails.
- To grade an answer against the documents it was given, the service has to return them. The RAG advisor puts them in the
  response metadata under `RetrievalAugmentationAdvisor.DOCUMENT_CONTEXT`.

```java {15,21,26}
import org.springframework.boot.test.context.TestConfiguration;
import org.springframework.boot.testcontainers.service.connection.ServiceConnection;
import org.springframework.context.annotation.Bean;
import org.testcontainers.ollama.OllamaContainer;

/** Real PostgreSQL with pgvector, and a real model in Ollama. {@code @ServiceConnection} sets the URLs. */
@TestConfiguration(proxyBeanMethods = false)
public class TestcontainersConfiguration {

    @Bean
    @ServiceConnection
    PostgreSQLContainer postgres() {
        return new PostgreSQLContainer(DockerImageName.parse("pgvector/pgvector:pg17").asCompatibleSubstituteFor("postgres"));
    }

    @Bean
    @ServiceConnection
    OllamaContainer ollama() {
        // Kept between runs when ~/.testcontainers.properties says testcontainers.reuse.enable=true, so the models
        // download once on your machine. CI never reuses, so cache the models there (see the gotchas).
        return new OllamaContainer("ollama/ollama:0.40.16")
                .withReuse(true);
    }
}
```

<CodeFile title="src/main/java/com/example/support/chat/SupportChatService.java">
```java {55,111,112,123}
package com.example.support.chat;

import java.nio.charset.StandardCharsets;
import java.util.List;
import java.util.Locale;
import java.util.Optional;
import java.util.UUID;
import java.util.function.Consumer;

import com.example.support.knowledge.KnowledgeFilters;
import com.example.support.tools.CustomerToolContext;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.messages.AssistantMessage;
import org.springframework.ai.chat.messages.Message;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.chat.model.Generation;
import org.springframework.ai.chat.prompt.Prompt;
import org.springframework.ai.document.Document;
import org.springframework.ai.model.tool.ToolCallDecision;
import org.springframework.ai.model.tool.ToolCallDecisions;
import org.springframework.ai.model.tool.ToolCallLimitExceededException;
import org.springframework.ai.model.tool.ToolCallingChatOptions;
import org.springframework.ai.model.tool.ToolCallingManager;
import org.springframework.ai.rag.advisor.RetrievalAugmentationAdvisor;
import org.springframework.ai.rag.retrieval.search.VectorStoreDocumentRetriever;
import org.springframework.ai.session.SessionService;
import org.springframework.ai.session.advisor.SessionAdvisors;
import org.springframework.stereotype.Service;

@Service
public class SupportChatService {

    static final String TOOL_LIMIT_ANSWER = "I couldn't finish looking that up. A support agent will follow up in this chat.";
    static final String CONFIRMATION_ANSWER = "Please confirm or decline this in the app.";
    static final String DECLINED = "The customer declined.";

    private static final Logger log = LoggerFactory.getLogger(SupportChatService.class);

    private final ChatClient supportChatClient;
    private final SessionService sessionService;
    private final ToolCallingManager toolCallingManager;
    private final SupportTools tools;

    public SupportChatService(ChatClient supportChatClient, SessionService sessionService,
                              ToolCallingManager toolCallingManager, SupportTools tools) {
        this.supportChatClient = supportChatClient;
        this.sessionService = sessionService;
        this.toolCallingManager = toolCallingManager;
        this.tools = tools;
    }

    public SupportAnswer ask(String userId, UUID chatId, String product, String question, Locale language) {
        return answer(userId, chatId, language, request -> request
                .user(question)
                // Replaces the retriever's default filter, so it must keep the audience condition.
                .advisors(advisor -> advisor.param(VectorStoreDocumentRetriever.FILTER_EXPRESSION,
                        KnowledgeFilters.customerDocuments(product))));
    }

    /** The tool calls waiting for the customer's decision: the session's last message, when it is an unanswered call. */
    public List<AssistantMessage.ToolCall> awaitingConfirmation(String userId, UUID chatId) {
        return pausedReply(sessionId(userId, chatId)).map(AssistantMessage::getToolCalls).orElse(List.of());
    }

    /** Runs the calls the customer confirmed, or tells the model they declined, and returns the model's answer. */
    public SupportAnswer confirm(String userId, UUID chatId, boolean approved, Locale language) {
        AssistantMessage paused = pausedReply(sessionId(userId, chatId)).orElseThrow(NothingToConfirmException::new);
        // Every call of the reply needs a decision, the ones that didn't need confirmation too.
        var decisions = new ToolCallDecisions(ToolCallDecisions.toolCallKeys(paused).stream()
                .map(key -> approved ? ToolCallDecision.allow(key) : ToolCallDecision.deny(key, DECLINED))
                .toList());
        var options = ToolCallingChatOptions.builder()
                .toolCallbacks(tools.callbacks())
                .toolContext(CustomerToolContext.of(userId))
                .build();
        List<Message> history = toolCallingManager
                .executeToolCalls(new Prompt(List.of(), options), new ChatResponse(List.of(new Generation(paused))), decisions)
                .conversationHistory();
        // The session holds the question and the paused reply; send only the tool results.
        return answer(userId, chatId, language, request -> request.messages(history.getLast()));
    }

    public void forget(String userId, UUID chatId) {
        sessionService.delete(sessionId(userId, chatId));
    }

    private SupportAnswer answer(String userId, UUID chatId, Locale language,
                                 Consumer<ChatClient.ChatClientRequestSpec> request) {
        ChatClient.ChatClientRequestSpec spec = supportChatClient.prompt()
                .toolContext(CustomerToolContext.of(userId))
                .advisors(SessionAdvisors.session(sessionId(userId, chatId)))
                .advisors(advisor -> advisor
                        .param(TokenBudgetAdvisor.USER_ID, userId)
                        .param(AnswerLanguageAdvisor.LANGUAGE, language));
        request.accept(spec);
        ChatResponse response = spec.call().chatResponse();
        Generation answer = response == null ? null : response.getResult();
        if (answer == null) {
            throw new IllegalStateException("The model returned no answer");
        }
        if (ToolCallDecisions.isAwaitingDecision(response)) {
            return new SupportAnswer(CONFIRMATION_ANSWER, List.of());
        }
        if (ToolCallLimitExceededException.FINISH_REASON.equals(answer.getMetadata().getFinishReason())) {
            log.warn("Tool call limit reached for {}: {}", userId, answer.getOutput().getText());
            return new SupportAnswer(TOOL_LIMIT_ANSWER, List.of());
        }
        List<Document> sources = response.getMetadata().getOrDefault(RetrievalAugmentationAdvisor.DOCUMENT_CONTEXT, List.of());
        return new SupportAnswer(answer.getOutput().getText(), sources);
    }

    private Optional<AssistantMessage> pausedReply(String sessionId) {
        List<Message> messages = sessionService.findById(sessionId) == null ? List.of() : sessionService.getMessages(sessionId);
        return messages.isEmpty() || !(messages.getLast() instanceof AssistantMessage reply) || !reply.hasToolCalls()
                ? Optional.empty()
                : Optional.of(reply);
    }

    /** The answer, and the knowledge chunks it was given. Evals check the answer against exactly these. */
    public record SupportAnswer(String text, List<Document> sources) {
    }

    /** A session id that only this user's chat maps to, so a chat id alone never reaches another user's session. */
    static String sessionId(String userId, UUID chatId) {
        return UUID.nameUUIDFromBytes((userId + ":" + chatId).getBytes(StandardCharsets.UTF_8)).toString();
    }
}
```

<CodeFile title="src/test/java/com/example/support/chat/SupportAnswerEvalTest.java">
```java {29,56,62,63,68}
package com.example.support.chat;

import static org.assertj.core.api.Assertions.assertThat;

import com.example.support.SupportIntegrationTest;
import com.example.support.chat.SupportChatService.SupportAnswer;
import com.example.support.knowledge.Audience;
import com.example.support.knowledge.KnowledgeIngestionService;
import java.util.List;
import java.util.Locale;
import java.util.UUID;
import org.junit.jupiter.api.Tag;
import org.junit.jupiter.api.Test;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.evaluation.FactCheckingEvaluator;
import org.springframework.ai.chat.evaluation.RelevancyEvaluator;
import org.springframework.ai.chat.prompt.ChatOptions;
import org.springframework.ai.evaluation.EvaluationRequest;
import org.springframework.ai.evaluation.Evaluator;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.io.ClassPathResource;
import org.springframework.test.context.ActiveProfiles;
import org.springframework.test.context.jdbc.Sql;

/** Grades real answers with a judge model. Slow and not free, so it runs in its own Gradle task, not in every build. */
@Tag("eval")
@SupportIntegrationTest
@ActiveProfiles({"it", "eval"})
@Sql("/orders.sql")
class SupportAnswerEvalTest {

    private static final Logger log = LoggerFactory.getLogger(SupportAnswerEvalTest.class);

    /** Questions the knowledge base answers. Add every question a customer complained about. */
    private static final List<String> GOLDEN_QUESTIONS = List.of(
            "How long does a refund take to reach my card?",
            "How many days do I have to ask for a refund?",
            "Which card do you send my refund to?",
            "How soon do you ship an order?",
            "How long does standard delivery take inside the EU?",
            "Where do I find my tracking number?");

    private static final double MIN_PASS_RATE = 0.8;

    @Autowired
    SupportChatService chat;

    @Test
    void answersStayRelevantAndGrounded(@Autowired KnowledgeIngestionService ingestion, @Autowired ChatClient.Builder judge,
                                        @Value("${support.eval.judge-model}") String judgeModel) {
        ingestion.ingest(new ClassPathResource("knowledge/refunds.md"), "billing", Audience.CUSTOMER);
        ingestion.ingest(new ClassPathResource("knowledge/shipping.md"), "billing", Audience.CUSTOMER);
        judge.defaultOptions(ChatOptions.builder().model(judgeModel).temperature(0.0));
        var relevancy = new RelevancyEvaluator(judge);
        var factChecking = FactCheckingEvaluator.builder(judge).build();

        List<EvaluationRequest> graded = GOLDEN_QUESTIONS.stream().map(this::answer).toList();

        assertThat(passRate(relevancy, graded)).as("relevancy pass rate").isGreaterThanOrEqualTo(MIN_PASS_RATE);
        assertThat(passRate(factChecking, graded)).as("fact-checking pass rate").isGreaterThanOrEqualTo(MIN_PASS_RATE);
    }

    private EvaluationRequest answer(String question) {
        SupportAnswer answer = chat.ask("eval-user", UUID.randomUUID(), "billing", question, Locale.ENGLISH);
        return new EvaluationRequest(question, answer.sources(), answer.text());
    }

    private static double passRate(Evaluator evaluator, List<EvaluationRequest> graded) {
        long passed = graded.stream().filter(request -> {
            boolean pass = evaluator.evaluate(request).isPass();
            if (!pass) {
                log.warn("{} failed: {} ({} sources) -> {}", evaluator.getClass().getSimpleName(), request.getUserText(),
                        request.getDataList().size(), request.getResponseContent());
            }
            return pass;
        }).count();
        return (double) passed / graded.size();
    }
}
```

## 4. Production gotchas & security

<Gotcha kind="reliability" title="Small models skip tools">
With the same two tool definitions, `qwen2.5:1.5b` asked for the order number it had just been given. `llama3.2:3b` called
`findOrder("1042")`. A test model that never calls tools makes every tool test fail, or worse, pass for the wrong reason. Check
your test model with one direct tool call before you build on it.
</Gotcha>

<Gotcha kind="cost" title="The first run downloads gigabytes">
`ollama/ollama` is 8.5 GB unpacked, and the models come on top. On your machine, set `testcontainers.reuse.enable=true` in
`~/.testcontainers.properties` so `withReuse(true)` keeps them. CI never reuses containers: cache the image, or build one with the
models inside using `OllamaContainer.commitToImage`. On Docker Desktop with WSL, `OllamaContainer` may ask for a GPU that isn't
there and fail with "WSL environment detected but no adapters were found". Clear the request with
`.withCreateContainerCmdModifier(cmd -> cmd.getHostConfig().withDeviceRequests(List.of()))`.
</Gotcha>

<Gotcha kind="reliability" title="A weak judge fails good answers">
In our run, a 3B judge said NO to every answer, correct ones included. When it answered in sentences, Spring AI read even
"Yes. The claim is supported…" as a fail. Use a judge stronger than the model under test, and before you trust its gate, run it on
answers you labelled yourself and count how often it agrees.
</Gotcha>

<Gotcha kind="reliability" title="An eval task without a classpath runs nothing, and the build stays green">
A registered `Test` task without `testClassesDirs` and `classpath` reports `NO-SOURCE` and succeeds. Your nightly eval job passes
without grading a single answer. Check that its report lists the tests.
</Gotcha>

<Gotcha kind="migration" title="Your test model is not your production model">
Thresholds and dimensions belong to an embedding model. The 0.5 similarity threshold was set for `text-embedding-3-small`; with
`nomic-embed-text`, "Where do I find my tracking number?" retrieved nothing. Integration tests prove the wiring. Only evals against
the production model tell you whether the answers are good.
</Gotcha>

## Recap

- Unit tests check your logic, integration tests check the wiring against real containers, and evals grade the answers.
- `@ServiceConnection` connects PostgreSQL and Ollama. Set `pull-model-strategy: when_missing` and a longer `timeout`.
- Assert on what stays fixed: tools called, values only a tool returns, sources retrieved. Never the wording.
- `RelevancyEvaluator` and `FactCheckingEvaluator` pass only on a bare "yes". Use a stronger judge, check it against labelled
  answers, and gate on a pass rate in a separate `evalTest` task.

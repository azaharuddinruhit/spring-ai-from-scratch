A `Prompt` is a list of messages plus options. Prompt engineering in Spring AI mostly means building that list well: a reviewed system
prompt kept in a resource file, user input passed in as template **parameters** (never concatenated), optional few-shot examples, and media where
the model supports it.

## 1. Spring mental model

| Concept | Spring analogy | Notes |
| --- | --- | --- |
| `SystemMessage` / `UserMessage` / `AssistantMessage` / `ToolResponseMessage` | Request headers vs body | System messages set the rules, user messages carry the request, assistant messages hold earlier replies, and tool messages carry results back. |
| `PromptTemplate` + `.st` file | A Thymeleaf view in `templates/` | Logic-free StringTemplate rendering against a model map. Variables are written `{name}` by default. |
| `.system(Resource)` / `@Value("classpath:…")` | `ResourceLoader` | Prompts are classpath resources, so they're versioned, diffable and testable. |
| `Media` on a `UserMessage` | A multipart attachment | The `MimeType` plus a `Resource`, `URL` or `URI`. Only user messages carry media. |
| `ImageModel`, `TranscriptionModel`, `TextToSpeechModel` | Specialized clients next to `RestClient` | Single-modality models with their own prompt and response types. |

The triage service combines a templated system prompt, a parameterized user message, a few-shot example and an optional screenshot.

<CodeFile title="src/main/java/com/example/support/TriageService.java">
```java {44,46}
package com.example.support;

import java.util.List;
import java.util.Objects;

import org.jspecify.annotations.Nullable;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.messages.AssistantMessage;
import org.springframework.ai.chat.messages.Message;
import org.springframework.ai.chat.messages.UserMessage;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.io.Resource;
import org.springframework.stereotype.Service;
import org.springframework.util.MimeType;

@Service
public class TriageService {

    /** One worked example teaches the expected format better than a paragraph of rules. */
    private static final List<Message> FEW_SHOT = List.of(
            new UserMessage("<ticket id=\"INC-1001\">Card payments fail with error 502 since 09:00.</ticket>"),
            new AssistantMessage("INC-1001 · P1 · Payment gateway returns 502. Check the upstream acquirer health first."));

    public record Screenshot(MimeType mimeType, Resource data) {}

    private final ChatClient chatClient;
    private final Resource systemPrompt;

    public TriageService(ChatClient chatClient,
                         @Value("classpath:/prompts/support-system.st") Resource systemPrompt) {
        this.chatClient = chatClient;
        this.systemPrompt = systemPrompt;
    }

    public String triage(String ticketId, String ticketText, @Nullable Screenshot screenshot) {
        String answer = chatClient.prompt()
                .system(s -> s.text(systemPrompt)
                        .param("product", "Acme Pay")
                        .param("tone", "calm, precise"))
                .messages(FEW_SHOT)
                .user(u -> {
                    u.text("<ticket id=\"{id}\">{body}</ticket>")
                            .param("id", ticketId)
                            .param("body", ticketText);        // user input is a value, never template text
                    if (screenshot != null) {
                        u.media(screenshot.mimeType(), screenshot.data());
                    }
                })
                .call()
                .content();
        return Objects.requireNonNullElse(answer, "");
    }
}
```
</CodeFile>

The controller accepts an optional screenshot and checks its media type against an allow-list before anything reaches the model.

<CodeFile title="src/main/java/com/example/support/TriageController.java">
```java {40-42}
package com.example.support;

import java.util.Set;

import org.jspecify.annotations.Nullable;
import org.springframework.http.HttpStatus;
import org.springframework.util.MimeType;
import org.springframework.util.MimeTypeUtils;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;
import org.springframework.web.server.ResponseStatusException;

@RestController
class TriageController {

    private static final Set<MimeType> ALLOWED_IMAGES = Set.of(MimeTypeUtils.IMAGE_PNG, MimeTypeUtils.IMAGE_JPEG);

    private final TriageService triage;

    TriageController(TriageService triage) {
        this.triage = triage;
    }

    @PostMapping("/tickets/{id}/triage")
    String triage(@PathVariable String id,
                  @RequestParam String text,
                  @RequestPart(required = false) @Nullable MultipartFile screenshot) {
        return triage.triage(id, text, toScreenshot(screenshot));
    }

    private static TriageService.@Nullable Screenshot toScreenshot(@Nullable MultipartFile file) {
        if (file == null || file.isEmpty()) {
            return null;
        }
        MimeType type = file.getContentType() == null ? null : MimeTypeUtils.parseMimeType(file.getContentType());
        if (type == null || !ALLOWED_IMAGES.contains(type)) {
            throw new ResponseStatusException(HttpStatus.UNSUPPORTED_MEDIA_TYPE, "Only PNG or JPEG screenshots are accepted");
        }
        return new TriageService.Screenshot(type, file.getResource());
    }
}
```
</CodeFile>

Audio and image generation use dedicated models. The OpenAI starter auto-configures `OpenAiAudioTranscriptionModel`,
`OpenAiAudioSpeechModel` and `OpenAiImageModel` next to the chat model. Inject them through their portable interfaces.

<CodeFile title="src/main/java/com/example/support/VoiceChannel.java">
```java {23-25}
package com.example.support;

import org.springframework.ai.audio.transcription.TranscriptionModel;
import org.springframework.ai.audio.tts.TextToSpeechModel;
import org.springframework.core.io.Resource;
import org.springframework.stereotype.Service;

/** Voicemail in, spoken answer out: transcription → triage → speech. */
@Service
public class VoiceChannel {

    private final TranscriptionModel transcription;
    private final TextToSpeechModel speech;
    private final TriageService triage;

    public VoiceChannel(TranscriptionModel transcription, TextToSpeechModel speech, TriageService triage) {
        this.transcription = transcription;
        this.speech = speech;
        this.triage = triage;
    }

    public byte[] answerVoicemail(String ticketId, Resource voicemail) {
        String transcript = transcription.transcribe(voicemail);
        String answer = triage.triage(ticketId, transcript, null);
        return speech.call(answer);                           // MP3 bytes by default for OpenAI
    }
}
```
</CodeFile>

package com.example.support;

import java.util.Optional;

import org.springframework.ai.image.ImageModel;
import org.springframework.ai.image.ImagePrompt;
import org.springframework.ai.image.ImageResponse;
import org.springframework.ai.openai.OpenAiImageOptions;
import org.springframework.stereotype.Service;

@Service
public class DiagramGenerator {

    private final ImageModel imageModel;

    public DiagramGenerator(ImageModel imageModel) {
        this.imageModel = imageModel;
    }

    /** Returns base64 PNG data, or empty when the provider returned no image. */
    public Optional<String> illustrate(String description) {
        ImageResponse response = imageModel.call(new ImagePrompt(
                "Clean, flat technical illustration: " + description,
                OpenAiImageOptions.builder()
                        .size("1024x1024")
                        .responseFormat("b64_json")
                        .build()));
        return Optional.ofNullable(response.getResult())
                .map(result -> result.getOutput().getB64Json());
    }
}

## 4. Production gotchas & security

<Gotcha kind="security" title="Concatenating user input into template text is prompt injection, and can crash the renderer">
`.user("Summarize: " + ticketText)` makes the user's text part of the **template**. A `{` in it breaks StringTemplate parsing, and instructions
in it carry the same weight as yours. Always pass user input through `.param(…)`, wrap it in delimiting tags, and tell the system
prompt to treat tagged content as data. Delimiting reduces injection risk but doesn't remove it. Module 6 adds real guardrails.
</Gotcha>

<Gotcha kind="reliability" title="JSON in a template needs different delimiters">
Literal JSON braces in a `.st` template collide with the default `{ }` variable syntax. Configure
`StTemplateRenderer.builder().startDelimiterToken('<').endDelimiterToken('>')` on the client with `.templateRenderer(…)`,
or keep schemas out of templates and let `entity(…)` add format instructions (Module 2).
</Gotcha>

<Gotcha kind="cost" title="Images are billed as tokens">
A full-resolution screenshot can cost more input tokens than the whole conversation. Downscale images before attaching them, limit upload size,
and only attach media when the task actually needs it.
</Gotcha>

<Gotcha kind="security" title="Never let the model fetch arbitrary URLs">
`u.media(type, url)` with a user-supplied URL can make the provider, and in some setups your server, fetch internal addresses (SSRF).
Download, validate and size-check the file yourself, then attach it as a `Resource`.
</Gotcha>

<Gotcha kind="reliability" title="Not every model sees images or hears audio">
Multimodal input works only with models that support it (for example Claude, GPT-4o/5, Gemini and Llava-family models on Ollama).
A text-only model fails or silently ignores the media. Check the model's capabilities when you switch providers.
</Gotcha>

## Recap

- Store prompts as `.st` resources and pass every dynamic value with `.param(…)`.
- Few-shot `UserMessage`/`AssistantMessage` pairs teach format better than long instructions.
- Attach media to the user message, and validate type and size first.
- Image, transcription and speech have dedicated `ImageModel`, `TranscriptionModel` and `TextToSpeechModel` interfaces.
